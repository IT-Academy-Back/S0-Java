# Sprint 0 - Desenvolupament

Aquest Sprint 0 serveix per començar el curs amb una base comuna. Abans d'entrar a PHP, Java, bases de dades, APIs o Spring Boot, necessites entendre com es treballa en un projecte de desenvolupament: com et mous pels fitxers, com guardes canvis, com prepares una entrega i com es comuniquen les parts d'una aplicació web.

També serveix perquè puguis començar a decidir si t'interessa més el frontend, el backend o la connexió entre totes dues parts. Per fer aquesta decisió, abans necessites veure una mica de cada peça, entendre el vocabulari bàsic i tenir una primera idea de què passa al navegador, què passa al servidor i com es comuniquen.

No busquem que dominis totes les eines ara. Busquem que tinguis prou context perquè la resta del curs tingui més sentit i perquè puguis avançar amb més criteri quan arribin Java, les APIs, les bases de dades i Spring Boot.

## Què faràs en aquest sprint

1. Una introducció al terminal, Linux i Bash per moure't per carpetes i executar comandes bàsiques.
2. Practicaràs Git i GitHub per començar a versionar projectes.
3. Veuràs com preparar una entrega amb `README`, `.gitignore` i commits ben redactats.
4. Observaràs els fonaments pràctics de la web amb DevTools.
5. Faràs un tast molt guiat de frontend usant HTML, CSS i Javascript
6. Implementaràs una primera lògica backend senzilla amb Java.
7. Implementaràs una primera lògica backend senzilla amb PHP.
